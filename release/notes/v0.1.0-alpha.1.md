# First Shopify alpha

Commerce Gateway provides a self-hosted, tenant-scoped JSON API for Shopify Admin GraphQL 2026-10: merchant OAuth, paginated product reads, durable asynchronous title updates, idempotency, signed notifications and provider lifecycle handling. This is an alpha pre-release for controlled adoption, including Myth AI integration.

## Install

Use a Linux Docker Engine host with Docker Compose v2, Bash, OpenSSL, curl, tar and sha256sum. Configure your own trusted HTTPS origin to forward to `127.0.0.1:3000` first. Replace the example origin below with the actual Myth AI gateway origin; no Myth AI production hostname is assumed.

```bash
set -euo pipefail
version=v0.1.0-alpha.1
case "$(uname -m)" in
  x86_64) arch=amd64 ;;
  aarch64|arm64) arch=arm64 ;;
  *) echo 'Supported hosts: Linux AMD64 or ARM64' >&2; exit 1 ;;
esac
archive="commerce-gateway-${version}-linux-${arch}.tar.gz"
base="https://github.com/mithundas79/commerce-gateway/releases/download/${version}"
curl --fail --location --remote-name "${base}/${archive}"
curl --fail --location --remote-name "${base}/${archive}.sha256"
sha256sum --check "${archive}.sha256"
tar -xzf "$archive"
cd commerce-gateway
bash release/install.sh https://gateway.example.com
```

Run this in a new installation directory. Preserve `.env`, `.secrets` and the database for reinstalls/upgrades; follow `release/README.md` for backup and upgrade instructions. Both bundles include the application/PostgreSQL images and checksummed setup guides. Installation requires no compiler or npm on the target host. Complete app credential configuration, the three compliance subscriptions, merchant OAuth and per-shop `APP_UNINSTALLED` registration using the included `release/shopify-lifecycle.md` before accepting merchant writes. The generated TOML needs no diagnostic filtering or uninstall-block removal.

## Coverage limits

**Live privacy events were not exercised:** no live `customers/data_request`, `customers/redact` or `shop/redact` delivery was tested. Coverage consists of deployed three-topic configuration/readback and automated synthetic privacy events with mocked Shopify transport and real PostgreSQL. A live uninstall pass does not establish live privacy delivery. Backups and data already delivered to clients need the operator's documented retention/deletion procedures.

CI qualifies type checking, build, component/contract tests, real PostgreSQL integration, package installation, Windows helper behavior and native AMD64/ARM64 bundle install/reinstall/backup/restore. Restore tests use separate empty Docker daemons sharing each CI runner's kernel and synthetic credentials. Latency benchmarks measure loopback API/PG admission, excluding Shopify network and worker completion; they are not a production saturation claim. The tag workflow rebuilds and qualifies both downloadable bundles before publishing this pre-release.
